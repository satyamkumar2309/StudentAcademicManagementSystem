# Project Statement

## 1. Problem Statement

Managing student academic information manually can make it difficult to maintain student details, course marks, attendance records, and academic performance in an organized manner.

The Student Academic Management System is developed as a terminal-based Java application to provide a simple way to manage these academic records.

The system allows users to add, search, update, display, and delete student information. It also provides functionality for managing course marks and attendance, calculating academic performance, generating reports, and saving student records to text files.

---

## 2. Project Scope

The scope of the project includes:

- Managing student information.
- Managing course marks.
- Calculating total and average marks.
- Calculating overall grades.
- Managing attendance information.
- Calculating attendance percentage.
- Generating academic performance reports.
- Saving student records to text files.
- Reading saved student records.
- Validating user input.
- Demonstrating Java programming and Object-Oriented Programming concepts.

The current system is designed as a command-line application and does not include a graphical user interface or database.

---

## 3. Target Users

The intended users of the system are:

- Students who want to view or manage their academic information.
- Teachers or instructors who need a simple academic record management system.
- Beginners learning Java and Object-Oriented Programming.
- Academic project evaluators who want to observe practical implementation of Java concepts.

---

## 4. High-Level Features

The major features of the system are:

### Student Management

- Add student
- Display students
- Search student
- Update student
- Delete student

### Academic Management

- Add course marks
- Calculate total marks
- Calculate average marks
- Determine overall grade

### Attendance Management

- Store total classes
- Store attended classes
- Calculate attendance percentage
- Display attendance status

### Reporting and File Management

- Generate academic performance report
- Save student records
- Read saved student records
