# Student Academic Management System

## 1. Project Overview

The **Student Academic Management System** is a terminal-based Java application developed to manage basic academic information of students.

The system allows users to maintain student details, course marks, attendance records, academic performance, and saved student records through a simple menu-driven interface.

The project is designed to demonstrate important Java programming concepts such as classes, constructors, inheritance, method overloading, method overriding, abstract classes, interfaces, runtime polymorphism, exception handling, multithreading, loops, and Java I/O streams.

---

## 2. Objectives

The main objectives of this project are:

* To manage student information efficiently.
* To maintain course marks for students.
* To calculate total and average marks.
* To determine the overall grade of a student.
* To maintain and calculate attendance percentage.
* To generate academic performance reports.
* To save student records into files.
* To read previously saved student records.
* To demonstrate important Java Object-Oriented Programming concepts.
* To provide a simple terminal-based academic management system.

---

## 3. Features

The application provides the following features:

1. Add a new student.
2. Display all students.
3. Search for a student using Student ID.
4. Update student information.
5. Delete a student.
6. Add course marks.
7. Add attendance information.
8. Generate an academic performance report.
9. Save student records into a text file.
10. Read saved student records.
11. Demonstrate runtime polymorphism.
12. Calculate factorial using a looping statement.
13. Handle invalid user input using exception handling.

---

## 4. Major Functional Modules

### Student Management

This module manages basic student information such as:

* Student ID
* Student name
* Department

It supports adding, displaying, searching, updating, and deleting student records.

### Academic Management

This module manages course names and marks.

It calculates:

* Total marks
* Average marks
* Overall grade

### Attendance Management

This module stores:

* Total classes
* Attended classes

It calculates attendance percentage and displays the attendance status.

### Report and File Management

This module generates academic reports and allows student records to be saved to and read from text files.

## 9. How to Run

Open the project folder in the terminal.

Compile the Java source files:

```powershell
javac -d . src\*.java
```

Run the application:

```powershell
java -cp . Main
```

The menu-driven application will then start in the terminal.

## 11. Input Validation and Error Handling

The application validates user input and handles common errors.

Examples include:

* Invalid Student ID
* Non-numeric menu input
* Empty student name
* Empty department
* Invalid marks outside the range 0–100
* Invalid attendance values
* Negative factorial input
* Missing saved student record
* File input/output errors

Java exception handling using `try-catch` is used to prevent invalid input from terminating the application unexpectedly.

## 14. Project Limitations

The current version stores active student information in memory while the program is running.

Saved student records are stored as text files in the `data` folder.

The application does not currently use a database or graphical user interface.
